# Changelog

## 0.2.3 — publication candidate — 2026-10-21

- **54 profiles**, **431,570 inputs per profile**, **23,304,780 observations**, **1,431 vocabulary pairs**.
- Added native GPT-2 and original Llama 3, then 8 Kimi/Moonlight profiles covering 15 checkpoints. Kimi Dev is an exact existing Qwen 2.5 alias.
- Retained frozen v0.1/v0.2 results and added independently audited v0.3/v0.4 extension evidence. Historical runtime cohorts remain identified.
- Included full FLORES-200 dev/devtest, bounded MADLAD samples, UTF-16LE/BE fidelity, language-name search and overlapping continent groups.
- Selective downloads start empty, show storage/transfer scope, support cancellation/removal, and never run implicitly during a benchmark.
- Local runs accept custom tokenizer JSON and report vocabulary, fidelity, speed and memory. Full-sequence conversion uses cached assets only.
- Refreshed the four starter packages, source/explorer distributions, release manifests and current documentation. Native Windows/Linux/Intel Mac execution remains deferred.
- Fixed selected offline kits to retain and hash-check declared Kimi reference-source companions as data. They are never imported.
- Fixed environment checks to distinguish cached native GPT-2/o200k exports from missing or corrupt exports. Rebuilding the explorer selects the latest completed result cohort.

The private website and GitHub repository audience are unchanged. Preparing a candidate is separate from publishing it.

## 0.2.1 — 2026-10-20

Completed local GUI benchmark reports with vocabulary, UTF-8/UTF-16 fidelity, fresh-process throughput and process-memory measurements. Starter downloads select zero tokenizer and language payloads.

Expanded to **44 profiles**, **867 partitions**, **18,989,080 observations** and **946 pairs**, with tokenizer-family alias inventory, FLORES-200/MADLAD coverage, selected downloads, offline starter builders and the local launcher.
