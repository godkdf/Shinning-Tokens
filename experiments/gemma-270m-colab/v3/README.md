# V3 source

Open `../gemma_270m_colab_v5e1_V3.ipynb` in Google Colab Pro on one v5e-1 TPU, then Run all. The notebook is self-contained.

`base.py` supplies reusable V2 definitions. `extension.py` contains the V3 implementation. `build_notebook.py` assembles `runner.py`, the notebook, and the requirements/data documents without executing notebook code or running checks.

No local checks or tests were run. V3 measurements remain pending the user's Colab run.
